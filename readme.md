# Yu-Gi-Oh!

A dataset downloaded weekly from [https://ygoprodeck.com/](https://ygoprodeck.com/) and [published on Kaggle](https://www.kaggle.com/datasets/ioexception/yugioh-cards).

The data lives only on Kaggle. Each run of [kaggle-dataset-refresh](https://github.com/fferegrino/kaggle-dataset-refresh) downloads the latest version into `data/`, rebuilds it with `download.py`, and uploads a new version if any card, set or printing changed.
